可变参数（不定长参数）：不确定函数参数个数

1、位置传递：使用 *args接收参数，传入的参数会被args变量收集并合并为一个元组，

2、关键字传递：使用 **kwargs接收参数,参数需要是键值对，会被kwargs并合并为一个字典类型

def tuplefun(*args):
    return args
def dictfun(**kwargs):
    return kwargs

a1= tuplefun(1,2,3)
print(a1)
print(type(a1))

a2 = dictfun(k1="k1",k2="k2",k3="k3")
print(a2)
print(type(a2))
------------------------------
(1, 2, 3)
<class 'tuple'>
{'k1': 'k1', 'k2': 'k2', 'k3': 'k3'}
<class 'dict'>

四、Json格式转换

4.1 (dumps) Python类型转Json格式

import json

dict1 = {"name":"xiaoming","gender":"男","age":30,1:1}
list1 = [{"name":"xiaoming","gender":"男","age":30},{"name":"阿狸","gender":"女","age":22}]

#Python类型转json格式,ensure_ascii是为了输出汉字，否则会输出ascii码
print(json.dumps(dict1,ensure_ascii=False))
print(json.dumps(list1,ensure_ascii=False))
print(type(json.dumps(list1,ensure_ascii=False)))

---------------------------------------------------
{"name": "xiaoming", "gender": "男", "age": 30, "1": 1}
[{"name": "xiaoming", "gender": "男", "age": 30}, {"name": "阿狸", "gender": "女", "age": 22}]
<class 'str'>

4.5 (JSONEncoder) Python类型转JSON类型

JSONEncoder类由JSONEncoder()构造函数实例化。在编码器类中定义了以下重要方法

  • encode() -将Python对象序列化为JSON格式
  • iterencode() -对对象进行编码，并返回一个迭代器，生成对象中每个项目的编码形式。
  • **indent-**确定编码字符串的缩进级别
  • **sort_keys-**为true或false可以使键以排序顺序显示或不显示。
  • **Check_circular-**如果为True，则检查容器类型对象中的循环引用
import json

dict1 = {"name":"xiaoming","gender":"男","age":30}

#Python类型转json格式,ensure_ascii是为了输出汉字，否则会输出ascii码
js = json.JSONEncoder(ensure_ascii=False).encode(dict1)
print(type(js))
print(js)
----------------------------------
<class 'str'>
{"name": "xiaoming", "gender": "男", "age": 30}

5.2 常见魔术方法

  • __str__：类似Java的ToString方法，如果不定义，输出对象是对象的内容信息。

    class Student:
    name = None
    age = None
    sex = None

    # 构造方法
    def __init__(self, name, age, sex):
        self.name = name
        self.age = age
        self.sex = sex
        #print("构造方法执行")

    def __str__(self) -> str:
        return f"name:{self.name},age:{self.age},sex:{self.sex}"

stu = Student("小明", 22, "男")
print(stu)
---------------------------------
name:小明,age:22,sex:男

  • __lt__:设置对象大小比较规则

    class Student:
    name = None
    age = None
    sex = None

    # 构造方法
    def __init__(self, name, age, sex):
        self.name = name
        self.age = age
        self.sex = sex
        #print("构造方法执行")

    def __lt__(self, other):
        return self.age < other.age



stu = Student("小明", 22, "男")
stu1 = Student("小明1", 23, "男")
print(stu < stu1)

True

5.3 私有成员变量和方法

class Student:
    name = None
    age = None
    sex = None
    __money = None

    # 构造方法
    def __init__(self, name, age, sex,__money):
        self.name = name
        self.age = age
        self.sex = sex
        self.__money = __money
        #print("构造方法执行")


    def __whoAre(self, msg):
        print(f"我的名字是：{self.name}，我今年{self.age},性别：{self.sex},工资：{self.__money},{msg}")

    def publicFun(self):
        self.__whoAre("很高兴认识你")

stu = Student("小明", 22, "男",2000)
stu.publicFun()
#stu.__whoAre("很高兴认识你")  无法直接通过对象访问私有方法，会报错
-------------------------------------------
我的名字是：小明，我今年22,性别：男,工资：2000,很高兴认识你

5.4 继承

多继承语法如下：如果多个父类有同名属性或方法，则遵循左边优先原则

class Animal:
    name = None

    def getName(self):
        print(f"小黄是{self.name}")
        
from Animal import Animal

#单继承示例
class Dog(Animal):
    eat = None

    def getEat(self):
        print(f"喜欢吃{self.eat}")

dog = Dog()
dog.name = "一条狗"
dog.eat = '骨头'
dog.getName()#父类的方法
dog.getEat()
-------------------------------
小黄是一条狗
喜欢吃骨头

pass：补全语法，如果子类继承了多个父类，子类无需添加方法、属性。为了满足语法，需要加pass
