Oracle数据库导入导出及表空间操作（expdp、impdp）

Oracle数据库导入导出及表空间操作

Jul 25, 2023
阅读时长: 2 分钟

本文记录一下工作中遇到的Oracle使用expdp和impdp进行数据库导入导出操作。

一、导出操作

--1、查看当前实例，并切换实例 （源实例：devdb000、目标实例devdb001）
echo $ORACLE_SID
export ORACLE_SID=devdb000
sqlplus / as sysdba

---2、确认字符编码（验证源编码是：AMERICAN_AMERICA.ZHS16GBK）
select userenv('language') from dual; 


--3、查看目录并创建目录（用于保存dump文件）
drop directory PATH_PPN;--删除目录（若需要）
select * from dba_directories where DIRECTORY_NAME = 'PATH_PPN'; --查看目录
create directory PATH_PPN as '/oradata2/ppn27';--如果没有import_path则创建一个

--4、目录授权给数据库用户
grant read,write on directory PATH_PPN to ppn27;

--5、退出sqlplus
exit

--6、导出dump文件
expdp \'/ as sysdba\' directory=PATH_PPN dumpfile=ppn27.dmp logfile=ppn27.log schemas=ppn27
expdp \'/ as sysdba\' directory=PATH_PPN dumpfile=ppn27_preu_file.dmp logfile=ppn27_preu_file.log schemas=ppn27_preu_file

二、导入操作

--1、查看当前实例，并切换实例 （源实例：devdb000、目标实例devdb001）
echo $ORACLE_SID
export ORACLE_SID=devdb001
sqlplus / as sysdba

--2、创建新数据库用户及密码
create user ppn27utf8 identified by ppn27utf8;
create user ppn27fileutf8 identified by ppn27fileutf8;

--3、创建表空间（可选,也可以选择已有表空间）
CREATE TABLESPACE tbs_ppn_dev LOGGING DATAFILE '/oradata2/devdb001/tbs_ppn_dev.dbf' SIZE 512M AUTOEXTEND ON NEXT 32M MAXSIZE unlimited EXTENT MANAGEMENT LOCAL;

--4、设置数据库用户和表空间关联关系
alter user ppn27utf8 default tablespace tbs_ppn_dev;
alter user ppn27fileutf8 default tablespace tbs_ppn_dev;

--5、为用户授权(dba权限可选择是否授予)
grant dba,resource,connect to ppn27utf8;
grant dba,resource,connect to ppn27fileutf8;

--6、创建目录并授权给数据库用户
create directory PATH_PPN as '/oradata2/ppn27';
grant read,write on directory PATH_PPN to ppn27utf8;
grant read,write on directory PATH_PPN to ppn27fileutf8;


--7、导入数据
--（1）只导入表结构（排除索引、约束、统计）

impdp ppn27utf8/ppn27utf8 DIRECTORY=PATH_PPN DUMPFILE=ppn27.dmp logfile=ppn27_imp.log content=metadata_only  exclude=index,CONSTRAINT,STATISTICS REMAP_SCHEMA=ppn27:ppn27utf8  transform=segment_attributes:n remap_tablespace=TBS_PPNDEMO:tbs_ppn_dev

impdp ppn27fileutf8/ppn27fileutf8 DIRECTORY=PATH_PPN DUMPFILE=ppn27_preu_file.dmp logfile=imp_ppn27_file_metadata.log content=metadata_only  exclude=index,CONSTRAINT,STATISTICS REMAP_SCHEMA=ppn27_preu_file:ppn27fileutf8  transform=segment_attributes:n remap_tablespace=USERS:tbs_ppn_dev

--（2）执行字段长度扩展及字段类型转化脚本（运行部已提供），注意：在本操作执行完成后再导入数据
   
--（3）只导入纯数据
impdp ppn27utf8/ppn27utf8 DIRECTORY=PATH_PPN DUMPFILE=ppn27.dmp logfile=imp_ppn27_data.log content=DATA_ONLY exclude=index,CONSTRAINT,STATISTICS  REMAP_SCHEMA=ppn27:ppn27utf8  transform=segment_attributes:n remap_tablespace=TBS_PPNDEMO:tbs_ppn_dev

impdp ppn27fileutf8/ppn27fileutf8 DIRECTORY=PATH_PPN DUMPFILE=ppn27_preu_file.dmp logfile=imp_ppn27_file_data.log content=DATA_ONLY   exclude=index,CONSTRAINT,STATISTICS   REMAP_SCHEMA=ppn27_preu_file:ppn27fileutf8  transform=segment_attributes:n remap_tablespace=USERS:tbs_ppn_dev

--（4）导入索引等信息
impdp ppn27utf8/ppn27utf8 DIRECTORY=PATH_PPN DUMPFILE=ppn27.dmp logfile=imp_ppn27_metadata2.log include=index,CONSTRAINT,STATISTICS  REMAP_SCHEMA=ppn27:ppn27utf8  transform=segment_attributes:n remap_tablespace=TBS_PPNDEMO:tbs_ppn_dev

impdp ppn27fileutf8/ppn27fileutf8 DIRECTORY=PATH_PPN DUMPFILE=ppn27_preu_file.dmp logfile=imp_ppn27_file_metadata2.log include=index,CONSTRAINT,STATISTICS  REMAP_SCHEMA=ppn27_preu_file:ppn27fileutf8  transform=segment_attributes:n remap_tablespace=TBS_PPNDEMO:tbs_ppn_dev


--8、（可选）全量导入数据(若只需要进行数据库编码转换，执行此全量导入命令即可)
impdp ppn27utf8/ppn27utf8 DIRECTORY=PATH_PPN DUMPFILE=ppn27.dmp logfile=ppn27_imp.log  REMAP_SCHEMA=ppn27:ppn27utf8  transform=segment_attributes:n remap_tablespace=TBS_PPNDEMO:tbs_ppn_dev

impdp ppn27fileutf8/ppn27fileutf8 DIRECTORY=PATH_PPN DUMPFILE=ppn27_preu_file.dmp logfile=ppn27_file_imp.log  REMAP_SCHEMA=ppn27_preu_file:ppn27fileutf8  transform=segment_attributes:n remap_tablespace=USERS:tbs_ppn_dev

三、其他操作

--查询表空间列表
select tablespace_name from dba_tablespaces;

--查询表空间存储位置（注意表空间名称是大写）
select t1.name,t2.name  from v$tablespace t1,v$datafile t2 where t1.ts# = t2.ts# and t1.name='TBS_PPN_DEV_';

四、数据库扩容

1、增加新的数据文件:为表空间TBS_ZNWDZXFZGJ_DEV增加一个新的数据文件tbs_znwdzxfzgj_dev2.dbf
alter tablespace TBS_ZNWDZXFZGJ_DEV add datafile '/oradata2/devdb04/tbs_znwdzxfzgj_dev2.dbf' size 100M autoextend on next 10M;

2、对数据文件进行扩容,为新的数据文件tbs_znwdzxfzgj_dev2.dbf扩容至153600M大小
ALTER DATABASE DATAFILE '/oradata2/devdb04/tbs_znwdzxfzgj_dev2.dbf' RESIZE 153600M; 

3、数据文件大小扩容失败原因
但此处由于表空间TBS_ZNWDZXFZGJ_DEV创建的时候没有使用bigfile创建，单个数据文件上限只能是32g，所以此处如果想为表空间增加超大数据文件，只能多增加几个数据文件

4、创建bigfile表空间:创建bigfile表空间命令
create bigfile tablespace tbs_qylywxt datafile '/oradata/devdb04/tbs_qylywxt.dbf' size 100M autoextend on next 10M;

5、查看表空间的剩余空间容量（指的是数据文件的剩余空间）
select f.tablespace_name,d.file_name,f.bytes/1048576||'M' free_m from dba_free_space f,dba_data_files d where f.tablespace_name=d.tablespace_name and f.tablespace_name='TBS_ZNWDZXFZGJ_DEV';

6、修改表空间为自动扩展
alter database datafile '/oradata2/devdb04/tbs_znwdzxfzgj_dev7.dbf' autoextend on next 200M maxsize 32760M;

7、我们有两个途径创建bigfile表空间
(1).在数据库创建时指定缺省表空间类型为bigfile
create database aa set default bigfile tablespace...
这样我们创建表空间的时候，如果在create tablespace语句中没有设置表空间的类型为smallfile，则缺省创建bigfile表空间。

(2).在创建表空间时，指定表空间的类型为bigfile
create bigfile tablespace bigts datafile '/oradata/bigts01.dbf' size 50g.



8、bigfile表空间的几个特性，需要大家注意：
   A. bigfile的表空间创建时，自动设置为本地管理（extent management local)和段自动管理（segment management auto);如果你设置bigfile表空间为字典管理（extent management dictionary)或段手工管理（segment management manual),数据库将返回一个错误。
   B.bigfile表空间是单文件的，执行add datafile将报错，我们可以通过resize那个唯一的数据文件和设置表空间自动扩展来增加bigfile的表空间大小。
	alter tablespace bigtbs resize 80g;
	alter tablespace bigtbs autoextend on next 20g;
