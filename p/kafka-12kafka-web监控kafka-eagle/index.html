Dec 25, 2023
阅读时长: 1 分钟

一、Kafka-Eagle

Kafka-Eagle 框架可以监控 Kafka 集群的整体运行情况。官网：https://www.kafka-eagle.org/

我们使用kafka-eagle-bin-2.0.8版本。注意这个版本不支持Kraft 模式。所以我们使用带zookeeper的Kafka集群。

1.1 环境准备

Kafka-Eagle 的安装依赖数据库，我们此处使用 MySQL。前面在学习hive时已经安装过了。

1、我们创建数据库kafka-eagle:

2、Kafka-Eagle使用对于kafka的内存有要求，我们需要先修改对于参数：

修改/opt/module/kafka_2.12-3.0.2/bin/kafka-server-start.sh 命令中以下内容：

if [ "x$KAFKA_HEAP_OPTS" = "x" ]; then
    export KAFKA_HEAP_OPTS="-Xmx1G -Xms1G"
fi

修改为：
if [ "x$KAFKA_HEAP_OPTS" = "x" ]; then
 export KAFKA_HEAP_OPTS="-server -Xms2G -Xmx2G -XX:PermSize=128m -XX:+UseG1GC -XX:MaxGCPauseMillis=200 -XX:ParallelGCThreads=8 -XX:ConcGCThreads=5 -XX:InitiatingHeapOccupancyPercent=70"
 export JMX_PORT="9999"
 #export KAFKA_HEAP_OPTS="-Xmx1G -Xms1G"
fi

同步配置文件

[admin@hadoop1 bin]$ xsync kafka-server-start.sh

然后重启kafka服务。

[admin@hadoop1 bin]$ mykafka start

1.2 安装Kafka-Eagle

解压：

[admin@hadoop1 software]$ tar -zxvf kafka-eagle-bin-2.0.8.tar.gz

获得解压后的安装包：

[admin@hadoop1 kafka-eagle-bin-2.0.8]$ ll
total 79164
-rw-rw-r--. 1 admin admin 81062577 Oct 13  2021 efak-web-2.0.8-bin.tar.gz

再次解压：

[admin@hadoop1 kafka-eagle-bin-2.0.8]$ tar -zxvf efak-web-2.0.8-bin.tar.gz -C /opt/module/

[admin@hadoop1 efak-web-2.0.8]$ pwd
/opt/module/efak-web-2.0.8

[admin@hadoop1 efak-web-2.0.8]$ ll
total 0
drwxrwxr-x. 2 admin admin 33 Dec 28 15:49 bin
drwxrwxr-x. 2 admin admin 62 Dec 28 15:49 conf
drwxr-xr-x. 2 admin admin  6 Sep 13  2021 db
drwxrwxr-x. 2 admin admin 23 Dec 28 15:49 font
drwxr-xr-x. 9 admin admin 91 Sep 13  2021 kms
drwxr-xr-x. 2 admin admin  6 Sep 13  2021 logs

修改配置文件如下：

##配置zookeeper
efak.zk.cluster.alias=cluster1
cluster1.zk.list=hadoop1:2181,hadoop2:2181,hadoop3:2181/kafka


# offset 保存在 kafka
cluster1.efak.offset.storage=kafka
#cluster2.efak.offset.storage=zk

# 配置 mysql 连接
efak.driver=com.mysql.jdbc.Driver
efak.url=jdbc:mysql://hadoop1:3306/kafka-eagle?useUnicode=true&characterEncoding=UTF-8&zeroDateTimeBehavior=convertToNull
efak.username=root
efak.password=000000

配置环境信息

[admin@hadoop1 conf]$ sudo vim /etc/profile.d/my_env.sh
# kafkaEFAK
export KE_HOME=/opt/module/efak-web-2.0.8
export PATH=$PATH:$KE_HOME/bin

[admin@hadoop1 conf]$  source /etc/profile

启动Eagle

[admin@hadoop1 efak-web-2.0.8]$ bin/ke.sh start

注意，此处虽然给出了访问地址，但是由于我是内网机，直接使用这个外网IP无法访问，所以，我们使用 http://hadoop1:8048/ 访问即可。用户名密码：admin/123456
