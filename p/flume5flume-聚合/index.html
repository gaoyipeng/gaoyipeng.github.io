一、Flume 聚合

需求规划：

  • Flume-1 监控hadoop1节点的 group.log
  • Flume-2 监控hadoop2节点的 group1.log
  • Flume-3 （hadoop3节点）接收Flume-1、Flume-1的日志并打印到控制台。

（1）提前准备目录并在hadoop1上创建group.log文件，hadoop2上创建group1.log文件。

## 用于存放配置文件 /opt/module/apache-flume-1.9.0-bin/job/
[admin@hadoop1 job]$  mkdir group3
[admin@hadoop2 job]$  mkdir group3
[admin@hadoop3 job]$  mkdir group3

[admin@hadoop1 module]$ touch group.log
[admin@hadoop2 module]$ touch group1.log

（2）在3个节点的group3目录下创建Agent进程配置文件。

  • Flume-1对应Hadoop1的【 flume-exec-flume1.conf】，配置 Source 用于监控 group.log 文件，配置 Sink 输出数据到下一级 Flume。
  • Flume-2对应Hadoop2的【 flume-exec-flume2.conf】，配置 Source 用于监控 group1.log 文件，配置 Sink 输出数据到下一级 Flume。
  • Flume-3对应Hadoop3的【flume-flume-console.conf】，配置 source 用于接收 flume-1 与 flume-2 发送过来的数据流，最终合并后 sink 到控制台。

3个配置文件如下：

##【flume-exec-flume1.conf】
# Name the components on this agent
a1.sources = r1
a1.sinks = k1
a1.channels = c1

# Describe/configure the source
a1.sources.r1.type = exec
a1.sources.r1.command = tail -F /opt/module/group.log
a1.sources.r1.shell = /bin/bash -c

# Describe the sink
a1.sinks.k1.type = avro
a1.sinks.k1.hostname = hadoop3
a1.sinks.k1.port = 4141

# Describe the channel
a1.channels.c1.type = memory
a1.channels.c1.capacity = 1000
a1.channels.c1.transactionCapacity = 100

# Bind the source and sink to the channel
a1.sources.r1.channels = c1
a1.sinks.k1.channel = c1

##【flume-exec-flume2.conf】
# Name the components on this agent
a2.sources = r1
a2.sinks = k1
a2.channels = c1

# Describe/configure the source
a2.sources.r1.type = exec
a2.sources.r1.command = tail -F /opt/module/group1.log
a2.sources.r1.shell = /bin/bash -c

# Describe the sink
a2.sinks.k1.type = avro
a2.sinks.k1.hostname = hadoop3
a2.sinks.k1.port = 4141

# Describe the channel
a2.channels.c1.type = memory
a2.channels.c1.capacity = 1000
a2.channels.c1.transactionCapacity = 100

# Bind the source and sink to the channel
a2.sources.r1.channels = c1
a2.sinks.k1.channel = c1

##【flume-flume-console.conf】
# Name the components on this agent
a3.sources = r1
a3.sinks = k1
a3.channels = c1
# Describe/configure the source
a3.sources.r1.type = avro
a3.sources.r1.bind = hadoop3
a3.sources.r1.port = 4141
# Describe the sink
# Describe the sink
a3.sinks.k1.type = logger
# Describe the channel
a3.channels.c1.type = memory
a3.channels.c1.capacity = 1000
a3.channels.c1.transactionCapacity = 100
# Bind the source and sink to the channel
a3.sources.r1.channels = c1
a3.sinks.k1.channel = c1

（3）依次启动对应的 flume Agent进程： flume-exec-flume1，flume-exec-flume2，flume-flume-console。

##hadoop1
[admin@hadoop1 apache-flume-1.9.0-bin]$ bin/flume-ng agent --conf conf/ --name a1 --conf-file job/group3/flume-exec-flume1.conf &
##hadoop2
[admin@hadoop2 apache-flume-1.9.0-bin]$ bin/flume-ng agent --conf conf/ --name a2 --conf-file job/group3/flume-exec-flume2.conf &
##hadoop3
[admin@hadoop3 apache-flume-1.9.0-bin]$ bin/flume-ng agent --conf conf/ --name a3 --conf-file job/group3/flume-flume-console.conf -Dflume.root.logger=INFO,console

然后分别在hadoop1、hadoop2向日志文件添加数据。

[admin@hadoop1 module]$ echo 'hadoop1' > /opt/module/group.log
[admin@hadoop1 module]$ echo 'hadoop11' > /opt/module/group.log
[admin@hadoop1 module]$ echo 'hadoop111' > /opt/module/group.log

[admin@hadoop2 apache-flume-1.9.0-bin]$ echo 'hadoop2' > /opt/module/group1.log
[admin@hadoop2 apache-flume-1.9.0-bin]$ echo 'hadoop22' > /opt/module/group1.log
[admin@hadoop2 apache-flume-1.9.0-bin]$ echo 'hadoop221' > /opt/module/group1.log

此时hadoop3控制台可以看到hadoop1、hadoop2传输的数据。
