2、ES6新特性

2.1 let

let 关键字用来声明变量，使用 let 声明的变量有几个特点：

  1. 不允许重复声明
  2. 块儿级作用域
  3. 不存在变量提升
  4. 不影响作用域链
<!DOCTYPE html>
<html lang="en">
<head>

    <meta name="viewport" content="width=device-width, initial-scale=1.0">

</head>
<body>

        //声明变量
        let a;
        let b,c,d;
        let e = 100;
        let f = 521, g = 'iloveyou', h = [];

        //1. 变量不能重复声明,Uncaught SyntaxError: Identifier 'star' has already been declared
        let star = '罗志祥';
        let star = '小猪';

        //2. 块儿级作用域  全局, 函数, eval
        {
            let girl = '周扬青';
            //可正常打印
            console.log('作用域内'+girl);
        }
        //报错：ReferenceError: girl is not define
        console.log('作用域外'+girl);
        

        //3. 不存在变量提升，必须先定义，后使用
         console.log(song);
         let song = '恋爱达人';

        //4. 不影响作用域链，可正常打印，fu找不到school时，会向外查找变量

                console.log(school);
            }
            fn();
        }

            function fn1(){
                console.log(school1);
            }
            fn1();
            let school1 = '尚硅谷';
        }


    </script>
</body>
</html>

2.2 const

  1. 声明必须赋初始值
  2. 标识符一般为大写
  3. 不允许重复声明
  4. 值不允许修改
  5. 块级作用域

2.6 箭头函数

ES6 允许使用箭头（=>）定义函数。箭头函数的注意点:

  1. 箭头定义函数
// ES6 允许使用「箭头」（=>）定义函数。
//声明一个函数
let fn = function(){
}
let fn1 = (a,b) => {
	return a + b;
}
//调用函数
let result = fn1(1, 2);
console.log(result);
  1. 如果形参只有一个，则小括号可以省略。函数体如果只有一条语句，则花括号可以省略，函数的返回值为该条语句的执行结果
//1) 省略小括号, 当形参有且只有一个的时候
let add = n => {
    return n + n;
}
console.log(add(9));
//2) 省略花括号, 当代码体只有一条语句的时候, 此时 return 必须省略，而且语句的执行结果就是函数的返回值
let pow = n => n * n;
console.log(pow(8));

  1. 箭头函数 this 指向函数声明时所在作用域下 this 的值,其他this用法参考《ES6知识点笔记（1）》
function getName(){
    console.log(this.name);
}
let getName2 = () => {
    console.log(this.name);
}

//设置 window 对象的 name 属性
window.name = '尚硅谷';
const school = {
    name: "ATGUIGU"

//直接调用,此时this均指向window

getName.call(school);
getName2.call(school);

2.7 rest参数

上面已经介绍了箭头函数无法使用arguments，es6引入了rest参数(…)。Rest运算符用于函数定义中，以收集多个参数为一个数组。它的基本语法是三个点（...）

function date(){
    console.log(arguments);
}
date('白芷','阿娇','思慧');

// rest 参数
let date1 = (...args) => {
    console.log(args);// filter some every map 
}
date1('阿娇','柏芝','思慧');

// rest 参数必须要放到参数最后
let fn = (a,b,...args)  =>{
    console.log(a);
    console.log(b);
    console.log(args);
}
fn(1,2,3,4,5,6);

2.8 spread 扩展运算符

Spread运算符用于数组和对象的展开，将可迭代的对象展开为单独的元素。它同样使用三个点（...），但用法与Rest相反。

const numbers = [1, 2, 3];  
const moreNumbers = [4, 5, ...numbers];  

console.log(moreNumbers); // 输出: [4, 5, 1, 2, 3]

2.9 Symbol

es5原有6种原始数据类型是string、number、Boolean、Undefined、Null、Object

es6引入了Symbol。表示独一无二的值。是一种类似于字符串的数据类型。

（1) Symbol 的值是唯一的，用来解决命名冲突的问题

//创建Symbol
let s = Symbol();
console.log(s, typeof s);//Symbol() 'symbol'

//每次调用 Symbol 函数时，都会生成一个全新的、唯一的 Symbol，即使传入相同的描述字符串。
const s1 = Symbol('example');  
const s2 = Symbol('example');  
console.log(s1 === s2); // false  

//Symbol.for 会检查是否已有相同的 key 的 Symbol。如果存在，则返回该 Symbol，如果不存在，则创建一个新的 Symbol 并将其注册到全局 Symbol 注册表中。
const s3 = Symbol.for('example');  
const s4 = Symbol.for('example');  
console.log(s3 === s4); // true

（2) Symbol 值不能与其他数据进行运算

//不能与其他数据进行运算
const s5 = Symbol(20);  
console.log(s5)

let result = s5 + 100;
console.log(result)

（3) 使用Reflect.ownKeys 来获取对象的所有键名

Symbol 定义的对象属性不能使用for…in循环遍历 ，但是可以使用Reflect.ownKeys 来获取对象的所有键名

Reflect.ownKeys 是一个用于获取对象自身所有属性的函数，它不仅可以返回字符串属性的键，还可以返回 Symbol 类型的键。这样，我们可以使用 Reflect.ownKeys 来全面检查一个对象的所有属性键，包括 Symbol 类型的属性。

// 创建 Symbol  
const symbol1 = Symbol('symbol1');  
const symbol2 = Symbol('symbol2');  

// 创建对象，包含字符串属性和 Symbol 属性  
const obj = {  
    name: 'Alice',  
    age: 30,  
    [symbol1]: '这是一个 Symbol 属性',  
    [symbol2]: '这是另一个 Symbol 属性'  
};  

// 使用 Reflect.ownKeys 获取所有属性  
const keys = Reflect.ownKeys(obj);  

console.log(keys); // 输出: ["name", "age", Symbol(symbol1), Symbol(symbol2)]  

// 使用属性和符号属性  
keys.forEach(key => {
    console.log(`${String(key)}: ${obj[key]}`);  
});

// 输出:  
// name: Alice  
// age: 30  
// Symbol(symbol1): 这是一个 Symbol 属性  
// Symbol(symbol2): 这是另一个 Symbol 属性

（4）Symbol 创建对象属性

可以使用方括号 ([]) 将 Symbol 作为对象的属性

const say = Symbol('say');
const zibao = Symbol('zibao');

let youxi = {
    name:"狼人杀",
    [say]: function(){
    	console.log("我可以发言")
    },
    [zibao]: function(){
    	console.log('我可以自爆');
    }
}

youxi[say]();//我可以发言
youxi[zibao]();//我可以自爆

这种使用方式有什么意义呢？

①防止被覆盖
const key = 'unique';  
const anotherKey = 'unique';  

const obj = {  
	[key]: 'value1',  
	[anotherKey]: 'value2'  
};  

console.log(obj[key]); //value2  ，key的值被anotherKey覆盖了。

//使用Symbol不会有这个问题

const key = Symbol('unique');  
const anotherKey = Symbol('unique');  

const obj = {  
    [key]: 'value1',  
    [anotherKey]: 'value2'  
};  

console.log(obj[key]); //value1
②隐藏对象属性
const privateKey = Symbol('private');  

const obj = {  
	[privateKey]: 'I am private',  
	public: 'I am public'  
};  

console.log(Object.keys(obj)); // 输出: ['public']  ，Object.keys方法看不到privateKey，必须知道privateKey获取对应的值。
console.log(obj[privateKey]); // 输出: I am private

（5）Symbol内置属性

ES6 还提供了 11 个内置的 Symbol 属性。

名称 说明
Symbol.hasInstance 当其他对象使用 instanceof 运算符，判断是否为该对象的实例时，会调用这个方法
Symbol.isConcatSpreadable 对象的 Symbol.isConcatSpreadable 属性等于的是一个布尔值，表示该对象用于 Array.prototype.concat()时，是否可以展开。

2.10 Symbol.Iterator迭代器

单独介绍下遍历器（Symbol.Iterator）。它是一种接口，为各种不同的数据结构提供统一的访问机制。任何数据结构只要部署 Iterator 接口，就可以完成遍历操作。

（1）ES6 创造了一种新的遍历命令 for…of 循环

//声明一个数组
const xiyou = ['唐僧','孙悟空','猪八戒','沙僧'];

//使用 for...of 遍历数组
for(let v in xiyou){
	console.log(v,xiyou[v]);
}

//使用 for...of 遍历数组
for(let v of xiyou){
	console.log(v);
}

以上示例可以看到for…of循环与for…in循环的区别。

而Iterator 迭代器，机制如下：

  • a) 创建一个指针对象，指向当前数据结构的起始位置
  • b) 第一次调用对象的 next 方法，指针自动指向数据结构的第一个成员
  • c) 接下来不断调用 next 方法，指针一直往后移动，直到指向最后一个成员
  • d) 每调用 next 方法返回一个包含 value 和 done 属性的对象，最后一个元素返回done :true,表示结束.
let iterator = xiyou[Symbol.iterator]();

//调用对象的next方法
console.log(iterator.next());
console.log(iterator.next());
console.log(iterator.next());
console.log(iterator.next());
console.log(iterator.next());

（2）Symbol.iterator 接口主要供 for…of 消费

示例如下：

//声明一个对象
const banji = {
    name: "终极一班",
    stus: [
        'tom',
        'king',
        'xiaotian',
        'knight'
    ],
    [Symbol.iterator]() {
        //索引变量
        let index = 0;
        return {
            next: () => {
                if (index < this.stus.length) {
                    const result = { value: _this.stus[index], done: false };
                    //下标自增
                    index++;
                    //返回结果
                    return result;
                }else{
                    return {value: undefined, done: true};
                }
            }
        };
    }
}

//遍历这个对象 
for (let v of banji) {
    console.log(v);
}

2.11 生成器函数

生成器函数是 ES6 提供的一种异步管理解决方案。这样可以避免回调地狱问题。生成器函数的声明与普通函数类似，但使用 function* 关键字。生成器函数返回一个生成器对象，该对象具有 next() 方法，用于逐步执行生成器代码。

      • 的位置没有限制
    1. 生成器函数返回的结果是迭代器对象，调用迭代器对象的 next 方法可以得到yield 语句后的值
    1. yield 相当于函数的暂停标记，也可以认为是函数的分隔符，每调用一次 next方法，执行一段代码
    1. next 方法可以传递实参，作为 yield 语句的返回值
//生成器其实就是一个特殊的函数
function * gen(){
    yield [1,2,3]; 
    yield {name:'page'};
    yield 'string1111';
}
//可以通过iterator.next分段执行函数中的代码
let iterator = gen();
console.log(iterator.next());
console.log(iterator.next());
console.log(iterator.next());
console.log(iterator.next());
console.log('------------------------------------');
//遍历，也可以使用for...of遍历
for(let v of gen()){
    console.log(v);
}

（1）生成器函数参数

使用iterator.next可以传参，参数和对应的代码块匹配，第一个参数需要在方法调用处传入。

function * gen(arg){
    console.log(arg);
    let one = yield 111;
    console.log(one);
    let two = yield 222;
    console.log(two);
    let three = yield 333;
    console.log(three);
}

//执行获取迭代器对象
let iterator = gen('AAA');
console.log(iterator.next());
//next方法可以传入实参
console.log(iterator.next('BBB'));
console.log(iterator.next('CCC'));
console.log(iterator.next('DDD'));

（2）生成器函数异步管理场景

生成器函数本质上并不是异步的，但它们可以与异步操作结合使用，从而实现更为清晰的异步编程。通过使用生成器函数，可以暂停执行并在获取到异步操作的结果后再继续执行，避免了回调地狱。

场景：获取用户数据 、用户处理订单、 订单处理商品

function * gen(){
    let users = yield getUsers();
    let orders = yield getOrders();
    let goods = yield getGoods();
}

//调用生成器函数
let iterator = gen();
iterator.next();

function getUsers(){
    setTimeout(()=>{
        let data = '用户数据';

4.1 async/await

async/await是基于Promise的语法糖，使得异步代码看起来像同步代码，从而提高可读性，减少了回调地狱。

（1）在async/await语法中，async关键字用于标记一个函数为异步函数。它的主要作用是启用函数内部使用await。

  • 返回的结果不是一个 Promise 类型的对象, 代表成功，则执行Promise.prototype.then 方法
  • 返回的结果是一个 Promise 对象,如果执行 resolve 函数，则代表成功，如果执行reject函数，则代表失败
  • 如果抛出错误（throw new Error(‘出错啦!’)），则相当于返回一个失败的Promise 对象。则执行Promise.prototype.catch 方法
async function myfn(){
    return new Promise((resolve, reject)=>{
        //resolve('成功的数据');
        reject("失败的错误");
    });
}

const result = fn();

//调用 then 方法
myfn().then(value => {
	console.log(value);
}, reason => {
	console.warn(reason);
})

（2）await通常与async一起使用，目的是简化异步编程。在async函数内部，await用于暂停代码的执行，直到一个Promise被解决（fulfilled）或拒绝（rejected）。

await 返回的是 promise 成功的值。

// await 要放在 async 函数中.
async function main() {
    try {
        let result = await p;
        console.log(result);
    } catch (e) {
        console.log(e);
    }
}
//调用函数
main();

(3) 与ajax结合使用

// 发送 AJAX 请求, 返回的结果是 Promise 对象
function sendAJAX(url) {
    return new Promise((resolve, reject) => {
        //1. 创建对象
        const x = new XMLHttpRequest();
        //2. 初始化
        x.open('GET', url);
        //3. 发送
        x.send();
        //4. 事件绑定
        x.onreadystatechange = function () {
            if (x.readyState === 4) {
                if (x.status >= 200 && x.status < 300) {
                    //成功啦
                    resolve(x.response);
                }else{
                    //如果失败
                    reject(x.status);
                }
            }
        }
    })
}

// async 与 await 测试  axios
async function main(){
    //发送 AJAX 请求
    let result = await sendAJAX("http://jsonplaceholder.typicode.com/posts");
    console.log(result);
    //再次测试
    let tianqi = await sendAJAX('http://jsonplaceholder.typicode.com/posts/2')
    console.log(tianqi);
}

main();

5.2 正则扩展-命名捕获分组

需求，分别获取链接URL中的标签和文本。

不使用命名捕获分组：

//声明一个字符串
let str = '<a href="http://www.atguigu.com">尚硅谷</a>';

//提取 url 与 『标签文本』
const reg = /<a href="(.*)">(.*)<\/a>/;

//执行
const result = reg.exec(str);

console.log(result);
// console.log(result[1]);
// console.log(result[2]);

使用命名捕获分组：

let str = '<a href="http://www.atguigu.com">尚硅谷</a>';
//分组命名
const reg = /<a href="(?<url>.*)">(?<text>.*)<\/a>/;
const result = reg.exec(str);

console.log(result);
console.log(result.groups.url);
console.log(result.groups.text);

console.log(result1);
const result2 = arr.flatMap(item => [item * 10]);

7.2 Promise.allSettled、Promise.all

都用于获取批量异步任务的结果。

//声明两个promise对象
const p1 = new Promise((resolve, reject)=>{
    setTimeout(()=>{
        resolve('商品数据 - 1');
    },1000)
});

const p2 = new Promise((resolve, reject)=>{
    setTimeout(()=>{
        resolve('商品数据 - 2');
            //reject('出错啦!');
    },1000)
});

//调用 allsettled 方法
const result = Promise.allSettled([p1, p2]);
console.log(result);

const res = Promise.all([p1, p2]);
console.log(res);

Promise.allSettled永远成功（fulfilled）。如果2个两个promise对象均成功了fulfilled，那么2则返回结果如下

但若是两个promise对象请求失败的（注意p2返回了reject）：

//声明两个promise对象
const p1 = new Promise((resolve, reject)=>{
    setTimeout(()=>{
        resolve('商品数据 - 1');
    },1000)
});

const p2 = new Promise((resolve, reject)=>{
    setTimeout(()=>{
        //resolve('商品数据 - 2');
        reject('出错啦!');
    },1000)
});

//调用 allsettled 方法
const result = Promise.allSettled([p1, p2]);
console.log(result);

const res = Promise.all([p1, p2]);
console.log(res);
