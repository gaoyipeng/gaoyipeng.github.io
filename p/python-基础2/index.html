一、Python 文件操作

1.1 文件打开函数

f = open('D:/name.txt', 'w', encoding="UTF-8")

执行后，会在D盘生成一个新文件name.txt。

1.2 文件内容读取

#1、读取所有内容,read(num),num指定读取字节长度
f = open('D:/name.txt', 'r', encoding="UTF-8")
print(f.read()) 

#2、读取所有对象，以行为单位，放在数组中
f = open('D:/name.txt', 'r', encoding="UTF-8")
print(f.readlines())

#3、每次读取一行，以下代码，分别读取第一行和第二行
f = open('D:/name.txt', 'r', encoding="UTF-8")
print(f.readline())
print(f.readline())

#4、for 循环读取，每次读取一行
f = open('D:/name.txt', 'r', encoding="UTF-8")

#print(f.read())
for i in f:
    print(f"每行数据为：{i}")

1.3 文件关闭

#主动关闭文件占用
f = open('D:/name.txt', 'r', encoding="UTF-8")
for i in f:
    print(f"每行数据为：{i}")
f.close()

方式二：with open语法（自动关闭文件）

with open('D:/name.txt', 'r', encoding="UTF-8") as f:
    for i in f:
        print(f"每行数据为：{i}")

1.4文件写入

#文件写入，如果文件已经存在，则清空内容后写入，write只会将内容保存在内存中，flush才会写入磁盘
f = open('D:/name.txt', 'w', encoding="UTF-8")

f.write("123")
f.write("456")
f.write("789")
f.flush()

#文件添加
f = open('D:/name.txt', 'a', encoding="UTF-8")

f.write("aaa")
f.write("bbb")
f.write("ccc")
f.flush()

3.1 main变量和all 变量

#__main__变量可以做测试使用，同时当前文件作为模块被引入是，测试方法不会自动执行。
def test(a ,b):
    return a+b

if __name__ == '__main__':
    test(2,3)

#__all__限制作为模块被引用时可调用的方法。
# test.py
__all__ = [test]
def test(a ,b):
    return a+b
def test1(a ,b):
    return a+b


#main.py
import test
print(test.test(2,3))
print(test1.test(2,3)) #报错，无法使用test1

四、Python包

4.1 python包的定义和使用

#__all__同样适用于Python包。控制 import * 导入的内容。在__init__.py文件中定义

#__init__.py
__all__ = ['modu1']

# test.py 
from  my_pack import *

modu1.mfun()
modu2.mfun() #如果import * ，那么将无法使用modu2，此处编译不通过

4.2 安装第三方包

python默认将三方模块安装到site-packages, 并且python在执行的时候会搜索这个path(Python安装目录的 \Lib\site-packages)。

4.2.1 使用pip命令安装第三方包（pip是安装python时自带的）

如果下载国外包速度慢，可以使用镜像：

#pip 版本查看 pip --version
pip install pyecharts -i https://pypi.tuna.tsinghua.edu.cn/simple some-package

网站：https://mirrors.tuna.tsinghua.edu.cn/help/pypi/

五 Python操作Mysql

首先需要安装pymysql包


from pymysql import Connection

# 获取数据库连接
conn  = Connection(
    port=3306,
    host="127.0.0.1",
    user='root',
    password='123456'
)
print(conn.get_server_info()) #数据库版本信息

#获取游标
cursor = conn.cursor()
conn.select_db("world")

cursor.execute("select  * from city c where c.CountryCode  = 'NLD'")
resule = cursor.fetchall()

for i in resule:
    print( i)
print(resule)

conn.close()
