官方下载地址：http://kafka.apache.org/downloads.html，我们使用3.0.2版本来验证。

1.2 Kafka安装

上传安装包到hadoop1、hadoop2、hadoop3节点并解压：

[admin@hadoop1 software]$ tar -zxvf kafka_2.12-3.0.2.tgz -C /opt/module/

配置环境变量（3台都需要，root用户操作）：

[root@hadoop1 profile.d]# vim /etc/profile.d/my_env.sh

#KAFKA_HOME
export KAFKA_HOME=/opt/module/kafka_2.12-3.0.2
export PATH=$PATH:$KAFKA_HOME/bin

执行以下命令，使PATH生效：

source /etc/profile

1.3 修改kafka配置文件

提前创建数据文件夹，后续配置会用到。

[admin@hadoop1 config]$ mkdir /opt/module/kafka_2.12-3.0.2/datas

修改3个节点的配置文件：

[admin@hadoop1 config]$ vim /opt/module/kafka_2.12-3.0.2/config/server.properties

其中hadoop1如下:

broker.id=0
log.dirs=/opt/module/kafka_2.12-3.0.2/datas
zookeeper.connect=hadoop1:2181,hadoop2:2181,hadoop3:2181/kafka

其中hadoop2如下:

broker.id=1
log.dirs=/opt/module/kafka_2.12-3.0.2/datas
zookeeper.connect=hadoop1:2181,hadoop2:2181,hadoop3:2181/kafka

其中hadoop2如下:

broker.id=2
log.dirs=/opt/module/kafka_2.12-3.0.2/datas
zookeeper.connect=hadoop1:2181,hadoop2:2181,hadoop3:2181/kafka

注意：broker.id不能相同。这里需要使用Zookeeper，这个在hadoop集群搭建时已经安装好了。

1.4 Kafka启停脚本（root创建）

创建启停脚本文件：

[root@hadoop1 bin]# vim mykafka

#! /bin/bash
case $1 in
"start"){
 for i in hadoop1 hadoop2 hadoop3
 do
 echo " --------启动 $i Kafka-------"
 ssh $i "/opt/module/kafka_2.12-3.0.2/bin/kafka-server-start.sh -daemon /opt/module/kafka_2.12-3.0.2/config/server.properties"
 done
};;
"stop"){
 for i in hadoop1 hadoop2 hadoop3
 do
 echo " --------停止 $i Kafka-------"
 ssh $i "/opt/module/kafka_2.12-3.0.2/bin/kafka-server-stop.sh "
 done
};;
esac

为脚本文件授权：

[root@hadoop1 bin]#chmod 755 mykafka

1.5 启动kafka

在hadoop1节点启动kafka集群（用admin即可）：

[admin@hadoop1 ~]$ mykafka start
 --------启动 hadoop1 Kafka-------
 --------启动 hadoop2 Kafka-------
 --------启动 hadoop3 Kafka-------
[admin@hadoop1 ~]$ jps -ml|grep kafka
4169 kafka.Kafka /opt/module/kafka_2.12-3.0.2/config/server.properties
[admin@hadoop1 ~]$ mykafka stop
 --------停止 hadoop1 Kafka-------
 --------停止 hadoop2 Kafka-------
 --------停止 hadoop3 Kafka-------
