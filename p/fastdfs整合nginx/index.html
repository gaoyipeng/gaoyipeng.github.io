FastDFS整合Nginx

FastDFS整合Nginx

Jun 15, 2023
阅读时长: 2 分钟

一、前言

前面我们已经搭建好了Fastdfs集群。实现了文件的上传和下载测试，但是目前有2个问题：

  • 无法通过HTTP的方式直接下载文件。
  • storage server写完文件后，会由后台线程将文件同步至同group内其他的storage server。但是同步有时间间隔。客户端下载时如果没有完成同步操作，就会出现文件无法访问的错误。

为了解决以上2个问题，我们可以整合Nginx+fastdfs-nginx-module模块的方式来解决。

  • fastdfs-nginx-module可以重定向文件连接到文件上传时的源服务器取文件,避免客户端由于复制延迟导致的文件无法访问错误 。
  • Nginx可以实现通过http的方式访问已上传文件。

二、FastDFS整合Nginx

2.1、下载资源

首先我们准备好 fastdfs-nginx-module和nginx安装包：

Nginx下载地址：http://nginx.org/download/

 wget  http://nginx.org/download/nginx-1.18.0.tar.gz

2.2、修改mod_fastdfs配置

我们本次只在10.10.81.74上部署Nginx，首先我们复制配置文件 mod_fastdfs.conf 到 /etc/fdfs 目录中

cp /usr/local/fastdfs/fastdfs-nginx-module-V1.20/src/mod_fastdfs.conf /etc/fdfs/

分别vim /etc/fdfs/mod_fastdfs.conf 编辑配置文件，主要关注以下部分：

tracker_server=10.10.81.74:22122
tracker_server=10.10.81.75:22122

group_name=group1/group2

url_have_group_name = true
store_path_count=2

store_path0=/data/FASTDFS/fastdfs_storage_data
store_path1=/data/FASTDFS/fastdfs_storage_data1

group_count = 2

[group1]
group_name=group1
storage_server_port=23000
store_path_count=2
store_path0=/data/FASTDFS/fastdfs_storage_data
store_path1=/data/FASTDFS/fastdfs_storage_data


[group2]
group_name=group2
storage_server_port=23001
store_path_count=2
store_path0=/data/FASTDFS/fastdfs_storage_data1
store_path1=/data/FASTDFS/fastdfs_storage_data1

2.3、安装Nginx

Nginx 是基于 C 语言开发的，HTTP 模块使用了 pcre 来解析正则表达式，且可以使用 zlib 对 HTTP 包的内容进行 gzip 压缩，Nginx 不仅支持 HTTP 协议，还支持 HTTPS，HTTPS 需要 openssl 提供支持，所以安装 Nginx 之前必须先安装它所依赖的环境。

yum install -y gcc gcc-c++ pcre pcre-devel zlib zlib-devel openssl-devel

我们执行以下命令

##解压
tar -zxvf nginx-1.18.0.tar.gz
cd nginx-1.18.0

##添加 fastdfs-nginx-module 模块，指定 nginx 的安装路径
./configure --add-module=/usr/local/fastdfs/fastdfs-nginx-module-V1.20/src --prefix=/usr/local/nginx/
# 编译并安装
make && make install

但是在编译的过程中报错了：

网上解决方案是修改/usr/local/fastdfs/fastdfs-nginx-module-V1.20/src/config配置为如下内容。

ngx_addon_name=ngx_http_fastdfs_module

if test -n "${ngx_module_link}"; then
    ngx_module_type=HTTP
    ngx_module_name=$ngx_addon_name
    ngx_module_incs="/usr/include /usr/include/fastcommon/"
    ngx_module_libs="-lfastcommon -lfdfsclient"
    ngx_module_srcs="$ngx_addon_dir/ngx_http_fastdfs_module.c"
    ngx_module_deps=
    CFLAGS="$CFLAGS -D_FILE_OFFSET_BITS=64 -DFDFS_OUTPUT_CHUNK_SIZE='256*1024' -DFDFS_MOD_CONF_FILENAME='\"/etc/fdfs/mod_fastdfs.conf\"'"
    . auto/module
else
    HTTP_MODULES="$HTTP_MODULES ngx_http_fastdfs_module"
    NGX_ADDON_SRCS="$NGX_ADDON_SRCS $ngx_addon_dir/ngx_http_fastdfs_module.c"
    CORE_INCS="$CORE_INCS /usr/include /usr/include/fastcommon/"
    CORE_LIBS="$CORE_LIBS -lfastcommon -lfdfsclient"
    CFLAGS="$CFLAGS -D_FILE_OFFSET_BITS=64 -DFDFS_OUTPUT_CHUNK_SIZE='256*1024' -DFDFS_MOD_CONF_FILENAME='\"/etc/fdfs/mod_fastdfs.conf\"'"
fi

重新编译安装：

./configure --add-module=/usr/local/fastdfs/fastdfs-nginx-module-V1.20/src --prefix=/usr/local/nginx/

make && make install

依然报错~~

无奈之下继续尝试其他版本的 fastdfs-nginx-module，到作者的官网下载：

可以看到最老的版本是V1.2.0，点击提交，下载2017-04-04的v1.1.6版本

下载后是fastdfs-nginx-module-5e5f3566bbfa57418b5506aaefbe107a42c9fcb1.zip，我们上传文件解压并改名为fastdfs-nginx-module-V1.16，重新编译安装：

./configure --add-module=/usr/local/fastdfs/fastdfs-nginx-module-V1.16/src --prefix=/usr/local/nginx/

make && make install

编译安装成功：

2.4、配置Nginx

 listen       80;
        server_name  10.10.81.74;

        location / {
            root   html;
            index  index.html index.htm;
        }

       location /group1/M00 {
          root /data/FASTDFS/fastdfs_storage_data;
          ngx_fastdfs_module;
       }

       location /group2/M00 {
          root /data/FASTDFS/fastdfs_storage_data1;
          ngx_fastdfs_module;
       }

启动nginx并验证:

[root@host-192-168-3-97 logs]# /usr/local/nginx/sbin/nginx
ngx_http_fastdfs_set pid=14698
ngx_http_fastdfs_set pid=14698
