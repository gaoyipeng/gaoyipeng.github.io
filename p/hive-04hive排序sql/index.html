Hive排序SQL（Order By、Sort By 、Distribute By、Cluster By）

Sep 22, 2023
阅读时长: 2 分钟

一、全局排序（Order By）

Order By：全局排序，只有一个Reduce。

  • asc（ascend）：升序（默认）
  • desc（descend）：降序

不做详细介绍。

二、Reduce内部排序（Sort By ）

对于大规模的数据集order by的效率非常低。在很多情况下，并不需要全局排序，此时可以使用Sort by。

Sort by为每个reduce产生一个排序文件。每个Reduce内部进行排序，对全局结果集来说不是排序。

示例：根据部门编号降序查看员工信息

步骤1）设置reduce个数
set mapreduce.job.reduces=3;
 
步骤2）查看设置reduce个数
set mapreduce.job.reduces;
 
步骤3）根据部门编号降序查看员工信息
select * 
from emp 
sort by deptno desc;

步骤4）将查询结果导入到文件中（按照部门编号降序排序）
insert overwrite local directory '/opt/module/sortby-result'
 select * from emp sort by deptno desc;

三、分区（Distribute By）

Distribute By：在有些情况下，我们需要控制某个特定行应该到哪个Reducer，通常是为了进行后续的聚集操作。distribute by子句可以做这件事。distribute by类似MapReduce中partition（自定义分区），进行分区，结合sort by使用。

对于distribute by进行测试，一定要分配多reduce进行处理，否则无法看到distribute by的效果。

注意：

1．distribute by的分区规则是根据分区字段的hash码与reduce的个数进行模除后，余数相同的分到一个区。

2．Hive要求DISTRIBUTE BY语句要写在SORT BY语句之前。

需求：按部门分区，并将部门内薪资倒序排列。

1）查询部门数作为reduce个数：4
select count(*)  from (select e.deptno,count(*) from emp e group by e.deptno) s ;

2）查看设置reduce个数
hive (default)> set mapreduce.job.reduces=4;

3）根据部门编号降序查看员工信息
insert overwrite local directory '/opt/module/sortby-result1'
select
    *
from emp
distribute by deptno
sort by sal desc;

四、分区排序（Cluster By）

当distribute by和sort by字段相同时，可以使用cluster by方式。cluster by除了具有distribute by的功能外还兼具sort by的功能。但是排序只能是升序排序，不能指定排序规则为asc或者desc。

select 
    * 
from emp 
cluster by deptno;
