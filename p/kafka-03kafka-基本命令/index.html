一、Kafka 基本命令

1.1 主题（队列）命令

[admin@hadoop1 bin]$  bin/kafka-topics.sh

命令参数：

参数 描述
–bootstrap-server <String: server toconnect to> 连接的 Kafka Broker 主机名称和端口号，多节点逗号分隔
–topic <String: topic> 操作的 topic 名称。
–create 创建主题。
–delete 删除主题。
–alter 修改主题。
–list 查看所有主题。
–describe 查看主题详细描述。
–partitions <Integer: # of partitions> 设置分区数。
–replication-factor<Integer: replication factor> 设置分区副本。
–config <String: name=value> 更新系统默认的配置。

示例：

1）创建 2个 topic（first、second）:每个topic 3个分区，每个分区3个副本

[admin@hadoop1 kafka_2.12-3.0.2]$ bin/kafka-topics.sh --bootstrap-server hadoop1:9092 --create --partitions 3 --replication-factor 2 --topic first
Created topic first.

[admin@hadoop1 kafka_2.12-3.0.2]$ bin/kafka-topics.sh --bootstrap-server hadoop1:9092 --create --partitions 3 --replication-factor 2 --topic second
Created topic second.

选项说明：

  • –topic 定义 topic 名
  • –replication-factor 定义副本数
  • –partitions 定义分区数

2）查看当前服务器中的所有 topic

[admin@hadoop1 kafka_2.12-3.0.2]$ bin/kafka-topics.sh --bootstrap-server hadoop1:9092 --list
first
second

3、查看 first 主题的详情

[admin@hadoop1 kafka_2.12-3.0.2]$  bin/kafka-topics.sh --bootstrap-server hadoop1:9092 --describe --topic first
Topic: first    TopicId: hLJQf6d6TyGilLbFuNXvBw PartitionCount: 3       ReplicationFactor: 2    Configs: segment.bytes=1073741824
        Topic: first    Partition: 0    Leader: 0       Replicas: 0,1   Isr: 0,1
        Topic: first    Partition: 1    Leader: 2       Replicas: 2,0   Isr: 2,0
        Topic: first    Partition: 2    Leader: 1       Replicas: 1,2   Isr: 1,2

可以看到Partition分区 0、1、2共3个，每个分区2个Replicas副本，及分区副本Leader所在的节点（分别对应hadoop1、hadoop2、hadoop3节点的 broker.id）

4、修改分区数

注意：命令行方式下 分区数只能增加，不能减少。

##增加分区
[admin@hadoop1 kafka_2.12-3.0.2]$  bin/kafka-topics.sh --bootstrap-server hadoop1:9092 --alter --topic first --partitions 4
##查看
[admin@hadoop1 kafka_2.12-3.0.2]$ bin/kafka-topics.sh --bootstrap-server hadoop1:9092 --describe --topic first
Topic: first    TopicId: hLJQf6d6TyGilLbFuNXvBw PartitionCount: 4       ReplicationFactor: 2    Configs: segment.bytes=1073741824
        Topic: first    Partition: 0    Leader: 0       Replicas: 0,1   Isr: 0,1
        Topic: first    Partition: 1    Leader: 2       Replicas: 2,0   Isr: 2,0
        Topic: first    Partition: 2    Leader: 1       Replicas: 1,2   Isr: 1,2
        Topic: first    Partition: 3    Leader: 0       Replicas: 0,2   Isr: 0,2
 ##删除
[admin@hadoop1 kafka_2.12-3.0.2]$ bin/kafka-topics.sh --bootstrap-server hadoop1:9092 --alter --topic first --partitions 2
Error while executing topic command : Topic currently has 4 partitions, which is higher than the requested 2.
[2023-11-21 11:28:45,383] ERROR org.apache.kafka.common.errors.InvalidPartitionsException: Topic currently has 4 partitions, which is higher than the requested 2.
 (kafka.admin.TopicCommand$)

5、删除 topic

[admin@hadoop1 kafka_2.12-3.0.2]$ bin/kafka-topics.sh --bootstrap-server hadoop1:9092  --delete --topic first

1.2 生产者命令

[admin@hadoop1 kafka_2.12-3.0.2]$ bin/kafka-console-producer.sh --bootstrap-server hadoop1:9092 --topic first

命令参数：

参数 描述
–bootstrap-server <String: server toconnect to> 连接的 Kafka Broker 主机名称和端口号，多节点逗号分隔
–topic <String: topic> 操作的 topic 名称。

1.3 消费者命令

[admin@hadoop1 kafka_2.12-3.0.2]$ bin/kafka-console-consumer.sh

命令参数：

参数 描述
–bootstrap-server <String: server toconnect to> 连接的 Kafka Broker 主机名称和端口号，多节点逗号分隔
–topic <String: topic> 操作的 topic 名称。
–from-beginning 从头开始消费。
–group <String: consumer group id> 指定消费者组名称。

1.4 消息发送消费示例

##生产者
[admin@hadoop1 kafka_2.12-3.0.2]$ bin/kafka-console-producer.sh --bootstrap-server hadoop1:9092 --topic first

##消费者
[admin@hadoop2 kafka_2.12-3.0.2]$ bin/kafka-console-consumer.sh --bootstrap-server hadoop1:9092 --topic first

##消费者（包含历史消息）
[admin@hadoop2 kafka_2.12-3.0.2]$ bin/kafka-console-consumer.sh --bootstrap-server hadoop1:9092  --from-beginning --topic first
