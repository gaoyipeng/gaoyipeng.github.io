一、SpringBoot 自动配置原理

springboot用来简化Spring框架带来的大量XML配置以及复杂的依赖管理，往往可以通过引用对应的xxx-Starter包来实现某模块的自动化配置。让开发人员可以更加关注业务逻辑的开发。我们研究一下SpringBoot 自动配置的过程，并编写自定义的Spring Boot Starter。

1.1、环境说明

  • Idea 2022.2.3
  • SpringBoot 2.7.12

1.2、原理分析

官方说明文档：https://docs.spring.io/spring-boot/docs/2.7.12/reference/html/features.html#features.developing-auto-configuration

1.2.1 @SpringBootApplication

  • 该注解标注在 某个类上， 说明该类为 SpringBoot的主配置类，SpringBoot 就应该运行这个类的main()方法来启动SpringBoot的应用。点开它，我们能够发现，其实它是一个组合注解 。又着两个重要的注解 @SpringBootConfiguration 和 @EnableAutoConfiguration

1.2.2@SpringBootConfiguration

该注解标注在 某个类上， 说明该类为 SpringBoot的 配置类。

在该注解下注解为 @Conguration ，即为配置类。 因为SpringBoot中没有 像Spring那样的大量的配置文件，所以为了让SpringBoot 知道哪些是配置类，所以就需要有@Configuration。@Configuration是Spring下的配置类注解，@SpringBootConfiguration是SpringBoot下的配置类注解，是@Configuration的派生注解，二者的本质相同。

1.2.3 @EnableAutoConfiguration

@EnableAutoConfiguration 就是 为SpringBoot实现自动配置的核心注解。它的意思就是开启自动配置功能。

@EnableAutoConfiguration 的内部又有两个非常重要的注解，分别为：

  • @AutoConfigurationPackage
  • @Import(AutoConfigurationImportSelector.class)

下面我们分别介绍下这两部分的作用。

1.2.3.1 @AutoConfigurationPackage

@AutoConfigurationPackag 的实际内容是由一个 @Import注解来完成的。

@Import() 注解是Spring底层的一个注解，它的作用就是给容器中导入一个组件，也就是导入 AutoConfigurationPackages.Registrar.class 的组件 ，我们使用Debug模式启动，也进入 Registrar 类的内部，可以看到Registrar它导入一个 metadata（注解源信息）到PackageImport中， 然后获取这个包的包名 ，即SpringBoot主配置类所在的包的包名：com.example.fastdfsjava。

所以： @AutoConfigurationPackag 的作用就是将SpringBoot 主配置类所在的包 及其 下面的所有子包里面的所有组件 扫描到 Spring 容器中

1.2.3.2.2spring.factories版本差异

此处需要说明一下：我们上面截图可以看到一个spring.factories，我们可以看到这个文件中配置的不是AutoConfiguration类型的文件了。这个文件是springboot2.7之前的自动配置类。在2.7版本之后，改为使用org.springframework.Boot.autoconfig.AutoConfiguration.imports，而为了向下兼容，2.7版本中这2个文件同时存在。如果我们在spring.factories文件中添加自动配置类，也是可以被spring识别的。

但是官方后续版本将会放弃spring.factories这种方式。建议大家用最新的配置，避免后期升级springboot时有兼容性问题。

2.1.2 BeanProperties

创建一个类来获取配置文件中的属性定义并绑定到Java Bean或属性中。

package com.sxdx.demo.bean;

import org.springframework.boot.context.properties.ConfigurationProperties;
import org.springframework.stereotype.Component;

@Component
@ConfigurationProperties("acme")
public class BeanProperties {
    /**
     * enable
     */
    private Boolean enable;
    /**
     * name
     */
    private String name;

    public Boolean getEnable() {
        return enable;
    }

    public void setEnable(Boolean enable) {
        this.enable = enable;
    }

    public String getName() {
        return name;
    }

    public void setName(String name) {
        this.name = name;
    }

    @Override
    public String toString() {
        return "BeanProperties{" +
                "enable=" + enable +
                ", name='" + name + '\'' +
                '}';
    }
}

2.2 自动配置类

最重要的自动配置类。

package com.sxdx.demo.autoconfig;

import com.sxdx.demo.bean.BeanProperties;
import com.sxdx.demo.bean.MyBean;
import org.springframework.beans.factory.annotation.Autowired;
import org.springframework.boot.autoconfigure.AutoConfiguration;
import org.springframework.boot.autoconfigure.condition.ConditionalOnBean;
import org.springframework.boot.autoconfigure.condition.ConditionalOnClass;
import org.springframework.boot.autoconfigure.condition.ConditionalOnMissingBean;
import org.springframework.boot.autoconfigure.condition.ConditionalOnProperty;
import org.springframework.boot.context.properties.EnableConfigurationProperties;
import org.springframework.context.annotation.Bean;
import org.springframework.context.annotation.Configuration;

@Configuration
@EnableConfigurationProperties(BeanProperties.class)
@ConditionalOnClass(MyBean.class)
@ConditionalOnProperty(prefix = "acme",name = "enable",matchIfMissing = true)
public class demoAutoConfiguration {


    @Autowired
    private BeanProperties beanProperties;

    @Bean
    @ConditionalOnMissingBean
    public MyBean mybean() {
        System.out.println("-------初始化操作----------");
        return new MyBean(beanProperties.getName());
    }
}

  • @Configuration :表示这个是一个配置类

  • @EnableConfigurationProperties(BeanProperties.class) ：使 @ConfigurationProperties 注解的类生效，即我们的BeanProperties类

  • @ConditionalOnClass(MyBean.class)：只有存在MyBean类时，才才生效。

  • @ConditionalOnProperty(prefix = “acme”,name = “enable”,matchIfMissing = true)：只有配置文件中的属性定义acme.enable = true时才生效。

demoAutoConfiguration类中实例化了一个bean：mybean，如果自动配置成功，那么这个实例将会自动添加到Spring ioc容器中。
