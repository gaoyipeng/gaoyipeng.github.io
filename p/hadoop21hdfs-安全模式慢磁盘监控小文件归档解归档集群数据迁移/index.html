HDFS 安全模式、慢磁盘监控、小文件归档、解归档、集群数据迁移

Sep 05, 2023
阅读时长: 2 分钟

一、安全模式

1.1 安全模式概念

​ **安全模式：**文件系统只接受读数据请求，而不接受删除、修改等变更请求

（1）进入安全模式场景

​ ➢ NameNode 在加载镜像文件和编辑日志期间处于安全模式；

​ ➢ NameNode 再接收 DataNode 注册时，处于安全模式。

（2）退出安全模式条件

​ ➢ dfs.namenode.safemode.min.datanodes:最小可用 datanode 数量，默认 0

​ ➢ dfs.namenode.safemode.threshold-pct:副本数达到最小要求的 block 占系统总 block 数的百分比，默认 0.999f。（只允许丢一个块）

​ ➢ dfs.namenode.safemode.extension:稳定时间，默认值 30000 毫秒，即 30 秒

所以在集群启动后的30秒内，无法进行删除、修改等操作，等待30秒后，会自动解除。

1.2 安全模式操作命令

（1）bin/hdfs dfsadmin -safemode get （功能描述：查看安全模式状态）
（2）bin/hdfs dfsadmin -safemode enter （功能描述：进入安全模式状态）
（3）bin/hdfs dfsadmin -safemode leave（功能描述：离开安全模式状态）
（4）bin/hdfs dfsadmin -safemode wait （功能描述：等待安全模式状态）

1.3 安全模式应用

1.3.1 磁盘修复

如果数据块损坏，集群重启或者集群状态检查时，会进入安全模式，这种情况下集群只可读，影响操作使用。

此时执行命令，离开安全模式，那么集群会显示损坏的数据块信息：

$ hdfs dfsadmin -safemode leave
Safe mode is OFF

我们按照提示的信息，将损坏的数据块文件删除，集群就可以恢复正常。

二、慢磁盘监控

“慢磁盘”指的时写入数据非常慢的一类磁盘。严重时就会出现写入数据延时。那么如何发现满磁盘。

1）通过心跳未联系时间。

一般出现慢磁盘现象，会影响到 DataNode 与 NameNode 之间的心跳。正常情况心跳时间间隔是 3s。超过 3s 说明有异常。

2）fio命令，测试磁盘的读写性能

##安装fio
[admin@hadoop1 hadoop-3.1.3]$ sudo yum install -y fio

## 测试读数据速度
[admin@hadoop1 hadoop-3.1.3]$ sudo fio -filename=/home/admin/test.log -direct=1 -iodepth 1 -thread -rw=read -ioengine=psync -bs=16k -size=2G -numjobs=10 -runtime=60 -group_reporting -name=test_r

结果：

三、小文件归档、解归档

存档文件或 HAR 文件，是一个更高效的文件存档工具，它将文件存入 HDFS 块，在减少 NameNode 内存使用的同时，允许对文件进行透明的访问。具体说来，HDFS 存档文件对内还是一个一个独立文件，对 NameNode 而言却是一个整体。。

把/input 目录里面的所有文件归档成一个叫 input.har 的归档文件，并把归档后文件存储到/output 路径下

$ hadoop archive -archiveName input.har -p /input /output

查看归档文件：

[admin@hadoop1 hadoop-3.1.3]$ hadoop fs -ls har:///output/input.har
2023-09-06 16:24:05,764 INFO sasl.SaslDataTransferClient: SASL encryption trust check: localHostTrusted = false, remoteHostTrusted = false
Found 3 items
-rw-r--r--   3 admin supergroup         40 2023-09-05 13:57 har:///output/input.har/a.txt
-rw-r--r--   3 admin supergroup         47 2023-09-05 13:57 har:///output/input.har/b.txt
-rw-r--r--   3 admin supergroup         28 2023-09-05 13:58 har:///output/input.har/c.txt

解归档单个文件

[admin@hadoop1 hadoop-3.1.3]$ hadoop fs -cp har:///output/input.har/a.txt /
2023-09-06 16:25:28,014 INFO sasl.SaslDataTransferClient: SASL encryption trust check: localHostTrusted = false, remoteHostTrusted = false
2023-09-06 16:25:28,226 INFO sasl.SaslDataTransferClient: SASL encryption trust check: localHostTrusted = false, remoteHostTrusted = false

四、HDFS集群数据迁移

采用 distcp 命令实现两个Hadoop集群之间的递归数据复制

[admin@hadoop1 hadoop-3.1.3]$ bin/hadoop distcp hdfs://hadoop1:8020/input hdfs://hadoop9:8020/input
